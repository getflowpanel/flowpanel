# FlowPanel

> A typed admin panel for Next.js. Describe your Drizzle or Prisma tables in a typed config and get lists, forms, record pages and dashboards at /admin. Open source, MIT licensed.
> Admin panel for Next.js in one package: config builders, Drizzle and Prisma adapters, the App Router runtime, React UI and auth presets.

```bash
pnpm dlx @flowpanel/cli init
pnpm dev
```

Docs: https://flowpanel.tech/docs · Source: https://github.com/getflowpanel/flowpanel

Generated from every section of the documentation. Property tables come from the
packages' own TypeScript declarations. Code blocks are excerpts from that
documentation: blocks the docs mark `twoslash` are type-checked in CI,
`excerpt` blocks are illustrative and may omit surrounding code.
