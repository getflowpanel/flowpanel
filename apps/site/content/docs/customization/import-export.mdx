---
title: Import & export
description: Bulk CSV / JSON upload and download from the list toolbar.
---

## Export

Set `export` on a resource and the list toolbar gets an **Export** button that
downloads the rows currently on screen.

```ts
resource(schema.users, {
  columns: ["email", "name", "plan"],
  export: { formats: ["csv", "json"], fields: ["email", "name", "plan"] },
})
```

`formats` chooses `csv` and/or `json`; `fields` whitelists which columns are
exported (omit for all visible columns). Use `export: false` to hide the button.

## Import

Set `import` and the toolbar gets an **Import** button that uploads a CSV or
JSON file. Each row is created through the resource's normal `create` — so it's
validated against the schema, scoped, audited, and blocked when the admin is
[read-only](/docs/core-concepts/configuration) or a field is
[role-gated](/docs/customization/forms#role-gated-fields). Import can never write
more than the form.

```ts
resource(schema.users, {
  import: { formats: ["csv", "json"], fields: ["email", "name", "plan"] },
})
```

- **`formats`** — which file types the picker accepts (`csv` and/or `json`).
- **`fields`** — restrict which columns are read from the file; anything else in
  the file is ignored. Omit to accept every column the create schema knows.

CSV is parsed RFC-4180-style (quoted fields, `""` escapes, commas / newlines
inside quotes); the header row names the columns. JSON must be an array of
objects. Rows that fail validation are reported individually — the rest still
import, and the button shows a per-row summary.
