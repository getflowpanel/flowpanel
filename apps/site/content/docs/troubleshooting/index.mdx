description: Find a FlowPanel error by symptom, fix its cause, and verify the result.
kind: troubleshooting
---

Run `pnpm flowpanel doctor` first: it checks package versions, the generated routes, duplicate `@flowpanel/core` copies and the typecheck. Then find the symptom below.

## Setup and configuration

### “The admin renders, but navigation is empty”

`resources`, `dashboards` and `pages` are empty. Add a resource or run `pnpm flowpanel new <table>`. See [Getting started](/docs/introduction/getting-started#add-your-first-resource).

### “The admin renders without styles”

The admin layout does not import `admin.css`. Restore `@import "@flowpanel/kit/styles/admin.css";` and restart. See [Styling](/docs/customization/styling#use-the-generated-stylesheet).

### “defineAdmin throws when the app boots”

The config names something that does not exist or clashes: an unknown column, a duplicate or reserved name, a duplicate action key, a `rowClick: "drawer"` without a drawer, or an unresolved reference. The error names the config path and the closest match. See [How FlowPanel works](/docs/understand/how-flowpanel-works#from-schema-to-compiled-admin).

### “Column typos compile without an error”

The resource's row type fell back to `Record<string, unknown>`, usually because a Prisma model is missing from `FlowpanelResources`. Add it and make sure TypeScript includes the file. See [Type registry](/docs/reference/registry).

### “flowpanel init exits in CI”

`init` asks questions and CI has no terminal. Check the plan with `--dry-run --json`, then run `--yes`. See [flowpanel init](/docs/reference/cli#flowpanel-init).

## Authentication and access

### “Everything returns 403 after connecting Clerk”

`publicMetadata.role` is missing from the session token, stale, or not the required role. Add it to the token, set the role, and refresh the session. See [Authentication](/docs/guides/authentication#clerk).

### “Production refuses to start without requireRole”

A writable production admin needs `auth.requireRole`. Only a deliberately public admin may set `allowUnauthenticated: true`, and then only with `readOnly: true`. See [Authentication](/docs/guides/authentication#verify).

### “A tenant can address another tenant's row”

A resource has no scope, a custom query leaves out `ctx.scope`, or create accepts a tenant field from the form. See [Verify isolation](/docs/guides/multi-tenant-scope#verify-isolation).

## Data and forms

### “400 invalid JSON body”

The request says `application/json` but the body is not valid JSON. Send a JSON object, or let the form send its own content type.

### “A bulk action returns 422 without running”

The selection is over the action's cap or its input failed validation. Nothing ran. Send smaller batches. See [BulkAction](/docs/reference/actions#bulkaction).

### “Prisma cannot resolve a model delegate”

The resource name is not the PascalCase model name, or Prisma Client is stale. Use `"OrderItem"` for `prisma.orderItem` and run `prisma generate`.

### “A drawer tab shows fewer rows than the list”

A drawer's related tab shows the first 20 rows. Link to the filtered list for the rest. See [Drawer](/docs/build/detail-cards#drawer).

## Realtime and queues

### “Realtime works locally but not across instances”

The memory driver reaches one process only, the instances use different Redis settings, or a proxy buffers or closes the stream. See [Realtime](/docs/guides/realtime#verify-end-to-end).

### “A worker publishes but no browser refreshes”

The worker publishes in memory or with a different `keyPrefix`. Publish with `createPublisher` from `@flowpanel/kit/publish`, sharing the admin's `realtime` options. See [Publish from a worker](/docs/guides/realtime#publish-from-a-worker).

### “The queue page is blank or the board returns 401”

The browser cannot reach `boardUrl`, the board token is missing, or the proxy blocks board assets. Open the board URL directly and fix its auth or proxy. See [Queues](/docs/guides/queues#verify-and-troubleshoot).

## Customization

### “Charts package not installed”

Run `pnpm add recharts`. See [Charts](/docs/customization/charts).

### “A computed column will not sort, filter, edit or export”

A column without `field` has nothing to sort or filter on. Compute the value in a view, or keep it display-only. See [Joined or computed values](/docs/customization/column-renderers#joined-or-computed-values).

### “An ejected page still wins after re-enabling config”

Next.js routes files before FlowPanel's catch-all. Delete or move the ejected route. See [Reverse an eject](/docs/customization/eject#reverse-an-eject).

## Runtime

### “getRequestContext() called outside of a request scope”

The call is outside a request, or two copies of `@flowpanel/core` are installed. Use `tryGetRequestContext()` where the context is optional, and align FlowPanel package versions (`pnpm list @flowpanel/core`). See [Request-scoped access](/docs/reference/contexts#request-scoped-access).

### “Which widget is slow”

In development, a page with widgets taking 300 ms or more logs one line, slowest first:

```text
[flowpanel] slow widgets on /system: «Bans» (metric, /system section 1 widget 4) 1240 ms; «Pipeline» (custom, /system section 2 widget 1) 410 ms, 2 memo hits
```

Share the slow query with `ctx.query`, narrow it, or cap its range with `maxRange`. See [ctx.read](/docs/reference/contexts#ctxread).
