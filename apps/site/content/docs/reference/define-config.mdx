`defineAdmin` takes the config object, validates it, fills defaults, and returns
the `ResolvedAdminConfig` that `createFlowpanel` serves. It does no I/O, so a page,
script or test can import the config freely.

<ApiSignature path="../../packages/core/src/define-admin.ts" name="defineAdmin" />

## AdminDefinition

`adapter` and `auth` are required. Without the rest you get no resources, the
sidebar shell, English labels, no audit sink, in-process realtime and no rate limit.

<AutoTypeTable path="../../packages/core/src/types/config.ts" name="AdminDefinition" />

## AuthConfig

`session` and `role` run on every request, so keep them cheap. `session` receives
the request being served.

<AutoTypeTable path="../../packages/core/src/types/config.ts" name="AuthConfig" />

`requireRole` is the admin-wide gate. A config with no `requireRole`, no resource
`access` and no global `scope` serves every page to anonymous visitors, and `defineAdmin` warns
in development; `allowUnauthenticated: true` marks that as intended. In
production, a config without `auth.requireRole` refuses to start unless it sets
both `allowUnauthenticated: true` and `readOnly: true`.

The presets `withBetterAuth`, `withClerk`, `withNextAuth`, `withLucia` and
`devAuth` build an `AuthConfig`; see [Authentication](/docs/guides/authentication).

## ThemeConfig

<AutoTypeTable path="../../packages/core/src/types/config.ts" name="ThemeConfig" />

`components` is `Partial<FlowpanelComponentSlots>`; see
[theme slots](/docs/customization/styling#replace-a-shared-component).

`accent` and `cssVars` apply to `[data-flowpanel-root]` and
`[data-flowpanel-portal]` only, so the host's tokens are untouched.
`accentDark` and `cssVarsDark` apply in dark mode. Every `--fp-*` token can be
overridden:

```ts excerpt
theme: {
  brand: { name: "Acme", logo: "/logo.svg", href: "/" },
  accent: "262 83% 58%",
  accentDark: "262 90% 72%",
  cssVars: { "--fp-radius": "0.25rem" },
  cssVarsDark: { "--fp-text-1": "0 0% 98%" },
}
```

Colours are HSL triplets; an `hsl(...)` wrapper is removed for you.

`user` fills the account menu at the foot of the sidebar, or the end of the tab
strip. Return nothing and no menu renders:

```ts excerpt
theme: {
  user: (session) => ({
    name: session?.user?.name,
    email: session?.user?.email,
    avatar: session?.user?.image,
    items: [{ label: "Settings", href: "/settings" }],
    signOut: "/api/auth/signout",
  }),
}
```

## ShellConfig

`shell: "tabs"` is shorthand for `shell: { mode: "tabs" }`.

<AutoTypeTable path="../../packages/core/src/types/config.ts" name="ShellConfig" />

`ShellMode` is `"sidebar" | "tabs" | "bare"`:

- `"sidebar"`: left navigation and brand. The default.
- `"tabs"`: a tab strip above the content, for an admin under the host's own header.
- `"bare"`: no chrome; your layout supplies it. Toasts, the drawer, the command
  palette and realtime still mount.

`skipLink: false` removes the skip-to-content link when the host layout already
renders one.

### Navigation groups

`navGroup` on a dashboard, page, resource or queue moves its entry from its kind's
group into a named one. Groups appear in the order of their first entry. A
`{ label, collapsed: true }` group stays folded until it holds the current page.

```ts excerpt
const journals = { label: "Journals", collapsed: true } as const;

resource(schema.scraperRun, { plural: "Scraper runs", navGroup: journals });
resource(schema.aiRun, { plural: "AI runs", navGroup: journals });
resource(schema.category, { plural: "Categories", navGroup: "Reference data" });
```

With `shell: "tabs"` the groups flatten into one row of tabs, so a group's label
and `collapsed` do not show there.

## RateLimitConfig

`RateLimitConfig` is `RateLimitOptions` plus `per` (`"user"` or `"ip"`,
defaulting to `"user"`) and `enabled`.

```ts excerpt
type RateLimitOptions =
  | { driver: "memory"; limit: number; windowMs: number }
  | { driver: "redis"; url: string; limit: number; windowMs: number; keyPrefix?: string };
```

The memory driver counts per process; use Redis with more than one instance. A
caller over the limit gets `429`.

## RealtimeConfig

An alias of `PublisherOptions`. Without it, events reach only the process that
published them. See [Realtime](/docs/guides/realtime).

## LabelsConfig

Text for the built-in UI. Groups merge over the English defaults; an undefined
value keeps its default and an empty string is used as given. A component's own
placeholder or label prop wins.

`pagination.page`, `pagination.pageSize` and `bulkBar.selected` take `{n}`.

`plurals` holds count templates for languages whose count words change with the
number: a `PluralLabel` has one template per `Intl.PluralRules` category of
`formatting.locale`, with `other` as the fallback. `plurals.results` wins over
`table.result` and `table.results`, and `plurals.selected` over `bulkBar.selected`:

```ts excerpt
labels: {
  plurals: {
    results: { one: "{n} запись", few: "{n} записи", many: "{n} записей", other: "{n} записи" },
    selected: { one: "Выбрана {n}", few: "Выбраны {n}", other: "Выбрано {n}" },
  },
},
```

`formatCount(label, count, locale)` from `@flowpanel/core/labels` picks the form
for your own components. A preset's plural gives way to a string template you set
for the same count.

<AutoTypeTable path="../../packages/core/src/types/labels/config.ts" name="PluralLabel" />

`dateRange.locale` sets the calendar and count formatting, falling back to
`en-US`. `form.createTitle` and `form.editTitle` take `{label}`. `access` holds the
sign-in and access-denied screens shown when `auth.signInUrl` or
`auth.forbiddenUrl` is not set.

A Russian `formatting.locale` (`"ru"`, `"ru-RU"`) makes `RU_LABELS` the base that
`labels` merges over, so set only the strings you want different, such as
`labels: { actions: { new: "Добавить" } }`. Other locales use English. Import
`RU_LABELS` or `DEFAULT_LABELS` from `@flowpanel/kit` (or `@flowpanel/core/labels`
in browser code); `labels: DEFAULT_LABELS` keeps English under a Russian locale.

## ResolvedAdminConfig

What `defineAdmin` returns.

<AutoTypeTable path="../../packages/core/src/types/config.ts" name="ResolvedAdminConfig" />

`defineAdmin` throws if two resources share a name, two dashboards or pages
share a path, or two queues share a key.

It also throws when a config points at a resource name nothing resolves to —
`reference.resource` on a column or field, a drawer or detail tab's `resource`,
or a `table()` widget's `resource`. The names it checks against are the
*resolved* ones, so a Drizzle table declared as `pgTable("ai_usage", …)` is
`"ai_usage"` even when the exported variable is `aiUsage`. The error names the
config path and suggests the near match.

Bind the definition with `createFlowpanel(config)`, then mount its page and
handlers. The runtime comes from `@flowpanel/kit/next`:

```ts excerpt
// app/admin/[[...slug]]/page.tsx
import { createFlowpanel } from "@flowpanel/kit/next";
import config from "@/flowpanel.config";

const flowpanel = createFlowpanel(config);

export default flowpanel.page;
```

```ts excerpt
// app/api/flowpanel/[...route]/route.ts
import { createFlowpanel } from "@flowpanel/kit/next";
import config from "@/flowpanel.config";

const flowpanel = createFlowpanel(config);

export const { GET, POST, PUT, PATCH, DELETE, OPTIONS } = flowpanel.handlers;
```

## Default bulk delete

When a resource has delete enabled and declares no `bulkActions`, `defineAdmin`
injects a default `delete` bulk action. Set `delete.confirm` to replace its confirmation description. Opt out
with `bulkActions: []` or `delete: { disabled: true }`.

`readOnly: true` short-circuits the whole rule: a read-only admin rewrites
every resource to `bulkActions: []` (and empties `actions` and the drawer's
actions, disables create/update/delete, drops `import`, and clears every
column's `editable`), so no default delete is injected for any resource.

## Reserved names

`defineAdmin` throws when a resource name or queue key is `dashboards`, `drawer`
or `queues`: the admin's own routes use those URL segments. Change `options.name`
on the resource or `options.key` on the queue.

## Behavior beyond validation

Besides validating, `defineAdmin`:

1. **Fills `columns`** from `adapter.introspect(ref)` for any resource that
   omitted them, in introspection order. If the adapter cannot introspect the
   ref, or reports zero columns, that throws.
2. **Injects the default bulk delete** (above).
3. **Normalizes `paths.admin`** and every dashboard / page `path` — a missing
   leading `/` is added, a trailing one stripped.

`introspect` reads the table object or DMMF; it does not query the database.

### `paths` and a Next.js deployment `basePath`

`paths.admin` and `paths.api` are app-relative: they say where the admin sits inside
your app, not where the app sits under a domain. If `next.config` sets its own
`basePath`, leave both alone — Next serves and links everything under that prefix
already.

FlowPanel adds the deployment prefix for you to the requests the browser issues
by itself: the client fetches built from `paths.api`, the generated form actions
and the SSE endpoint. `Link`, router navigation and `revalidatePath` are prefixed
by Next and are left untouched. Only a fetch you write yourself against
`paths.api` needs the helper:

```ts excerpt
import { withDeploymentBasePath } from "@flowpanel/kit/react"; // or "@flowpanel/core/paths" on the server

await fetch(`${withDeploymentBasePath(config.paths.api)}/user/u1/actions/verify`, {
  method: "POST",
});
```

### Formatting

`formatting` decides how the admin renders values, on the server and in the
browser alike:

```ts excerpt
formatting: { locale: "ru-RU", timeZone: "Europe/Moscow", currency: "RUB" },
```

`locale` governs the `number` and `money` column formats and the date shape;
`currency` is the default for a `money` column that names none, and a column's own
`currency` still wins. A set `timeZone` is the one clock of the admin: server
strings, chart ticks and every `LocalTime` render in it, before and after
hydration. Left unset, the server and the first paint use UTC and a `LocalTime`
switches to the reader's own zone after hydration. A `LocalTime` given its own
`fallbackTimeZone` keeps that switch either way.

With no `locale`, dates print as `YYYY-MM-DD HH:mm` and numbers use `en-US` grouping.

### Identifiers in URLs

Record identifiers are percent-encoded into the URL and decoded once when the page
route reads them back, so an id containing `/`, `%`, `?`, `#` or a space addresses
the record it names. Configured dashboard and page paths keep their separators —
`/reports/weekly` stays two segments.

A row whose projection did not include the key column is displayed but not treated
as addressable: no selection, no inline editing, no row activation. Keep the key
column in `columns`, or in `detail.tabs[].fields`, wherever the table has to act
on rows.
