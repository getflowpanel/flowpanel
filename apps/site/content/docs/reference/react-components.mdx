The components the admin renders with, for custom slots, pages and `"bare"`-shell
chrome. Import them from `@flowpanel/kit/react` (or `@flowpanel/react`).

```ts excerpt
import { AutoForm, DataTable, useAdminTable } from "@flowpanel/kit/react";
```

Not listed here: `@flowpanel/kit/next/client` holds the runtime's client
components (`DrawerHost`, `CommandHost`, `DashboardActionsBar`,
`DataTableWithDrawerRows`, `CreateDrawer`, `DetailTabsClient`,
`SavedViewsDropdown`, `ResourceListSearch`, `ResourceListFilters`,
`ResourceListDeletedToggle`, `DashboardDateRange`, `DashboardFilters`,
`WidgetErrorBoundary`), and `@flowpanel/kit/client` holds
[`useAdminMutation`](/docs/reference/client).

| `LabelsProvider`, `useLabels` | Provider/reader for label overrides (pluralization, field labels). |
| `FormattingProvider`, `useFormatting` | Provider/reader for the resolved locale, time zone and currency. |
| `ApiBaseProvider`, `useApiBase` | Provider/reader for the API mount (`paths.api`, default `/api/flowpanel`), including a Next.js `basePath`. |

## Hooks

All hooks are client-only.

**`useLiveChannel(channel, onMessage, options?)`** subscribes to one SSE channel;
instances on the same channel share one `EventSource`. It returns a `LiveStatus`:
`idle`, `connecting`, `live`, `reconnecting`, or `offline` after six failed
attempts (retries continue).

```tsx excerpt
const status = useLiveChannel("resource.orders", (payload) => {
  console.log("order event", payload);
});
```

**`useAdminTable()`** reads and writes the list URL state (`?page=`, `?perPage=`,
`?q=`, `?sort=field:dir`, `?f_<field>=`). `pageSize` is `null` when the URL sets
none. Setters use `router.replace`.

```tsx excerpt
const { page, pageSize, sort, setPage, setSort } = useAdminTable();
```

**`useUrlState()`** reads and writes typed search params.

**`useTheme(options?)`** returns the theme and `toggle`/`setTheme`, stored in
`localStorage`.

```tsx excerpt
const { theme, toggle } = useTheme();
```

**`useToast()`** fires a toast under `ToastProvider` or `FlowpanelGlobals`.

```tsx excerpt
const toast = useToast();
toast.success("Saved");
```

**`useOptimisticAction(serverValue, applyPatch)`** wraps `useOptimistic` and
`useTransition` for an optimistic value with a pending flag.

**`useAdminCommand()`** controls the ⌘K palette.

**`useAdminDrawer()`** reads and writes `?drawer=<resource>:<id>` and `?drawerTab=`.

**`useDashboardParam(key, schema, fallback)`** reads and writes one dashboard
search param, validated by a Zod schema.

**`useRowNavigation()`** returns the navigation a clicked row performs.

**`useRowHrefClick(rows, rowHrefs)`** is a `DataTable` `onRowClick` for per-row
hrefs; a `null` entry is inert.

**`useMediaQuery(query)`** subscribes to a media query, `false` on the server.
`DataTable` switches to cards at `(max-width: 639px)`.

```tsx excerpt
const isMobile = useMediaQuery("(max-width: 639px)");
```

## Realtime

**`RealtimeProvider`** mounts one shared `EventSource` for its descendants and
coalesces their refreshes. `Flowpanel` mounts it; mount it yourself in a
`"bare"`-shell layout.

**`useRealtimeRefresh(channels, options?)`** runs a debounced `router.refresh()`
on any event on its channels.

```tsx excerpt
useRealtimeRefresh("resource.orders");
```

**`RealtimeRefresh`** is the same as a component that renders nothing.

```tsx excerpt
<RealtimeRefresh channels={["resource.orders", "scraper:tick"]} />
```

**`DevToolsPanel`** shows realtime status, channels and event count in
development; it renders `null` in production.

```tsx excerpt
{process.env.NODE_ENV !== "production" && <DevToolsPanel />}
```

## Theme utilities

Helpers behind `useTheme` and `ThemeScript`.

| Export | Purpose |
| --- | --- |
| `resolveTheme`, `readStoredTheme`, `writeStoredTheme`, `THEME_STORAGE_KEY` | Resolve the effective theme from storage + system preference, and read/write the stored choice. |

## Name collisions with `@flowpanel/kit`

These names are different declarations in `@flowpanel/kit` and here; alias one
when importing both.

| Name | In `@flowpanel/kit` | In `@flowpanel/kit/react` |
| --- | --- | --- |
| `TableWidget` | The `table()` builder's return **type** (`{ kind: "table"; options }`). | The **component** that renders one. |
| `CustomWidget` | The `custom()` builder's return **type**. | The **component** that wraps one. |
| `Tone` | The config-level tone vocabulary used by `format: "badge"`, widget `tone`, … | The same vocabulary, re-declared next to `formatNumber`. |
| `NumericFormat` | The widget/metric format union. | The same union, re-declared next to `formatNumber`. |
| `DrawerWidth` | `DrawerConfig["width"]`, the config option. | `DrawerProps["width"]`, the component prop — an identical union, declared separately. |

```ts excerpt
import type { TableWidget } from "@flowpanel/kit";
import { TableWidget as TableWidgetRenderer } from "@flowpanel/kit/react";
```

`FormActionResult` is declared here and in `@flowpanel/kit/next` with identical
members.

## UI primitives

`Dialog`, `Popover`, `Select`, `DropdownMenu`, `Tabs*`, `Button`, `Checkbox`,
`Input`, `Label`, `Skeleton` and `Switch` are shadcn components with their upstream
APIs. `buttonVariants` and `DefaultButton` accompany `Button`.
