## v0.3.0

### @flowpanel/adapter-drizzle

- Added the `sql` and `count` capabilities with bound parameters.
- Added `hasDefault` to column introspection.

### @flowpanel/adapter-prisma

- Added the `sql` and `count` capabilities through `$queryRaw` with bound parameters.
- Added `hasDefault` to column introspection.

### @flowpanel/charts

- Added a skeleton that holds the space until a chart mounts.
- Changed empty charts to use the configured labels.
- Changed pie charts to show their legend by default.
- Changed tooltips and ticks to format currency and dates with the admin's `formatting`.

### @flowpanel/cli

- Added better-auth, NextAuth, Clerk and Lucia detection to `init`, which scaffolds the matching preset.
- Changed the scaffolded layout to forward a CSP nonce to `ThemeScript`.
- Changed `doctor` to print the config's warnings, also under `--json`.
- Fixed the `init` install step on Windows.

### @flowpanel/core

- Added the `stat`, `kv`, `bars`, `funnel`, `list` and `table` widgets for dashboards and detail pages.
- Added `detail.title`, `subtitle`, `badge` and detail tabs with `sections`, `widgets`, `hide` and `sort`.
- Added `href`, `query`, `labels`, `row`, `sql` and `count` to `WidgetContext`.
- Added `withBetterAuth` and `@flowpanel/core/publish`, the realtime client for workers.
- Changed `formatting` to apply to every number and date.
- Changed `rowClick` to default to `"detail"` for a resource with `detail` and no `drawer`.
- Removed the unused `audit.retention`.

### @flowpanel/kit

- Added `llms.txt`, the reference documentation as one file.
- Added `@flowpanel/kit/publish` for publishing realtime events from workers.

### @flowpanel/next

- Added related tabs that resolve reference labels, paginate, sort and link to the full list.
- Added widgets inside detail tabs.
- Added a warning in `defineAdmin` when a create form cannot satisfy a required column.
- Added `data-fp-error` to every error surface.
- Changed row clicks to open the detail page.
- Changed validation messages to come from `labels.form`.
- Changed a failed adapter read to show an error card with a request id instead of the host error page.

### @flowpanel/react

- Added cards for the new widgets and a dashboard freshness stamp.
- Added the pager's range and a drawer link to the record page.
- Changed headers to wrap on narrow screens.
- Changed `formatNumber` to take the resolved `formatting` as well as a locale string.
- Removed `cmdk` from the reference picker, cutting the UI bundle from 72.3 kB to 69.6 kB brotli.

### @flowpanel/test

- Added `smokeAdmin(page, options)`, which fails on any 4xx/5xx, `console.error`, FlowPanel error surface or WCAG 2.2 AA violation.

## v0.1.0

### @flowpanel/adapter-bullmq

First public release. BullMQ queue dashboards for FlowPanel, backed by bull-board.

### @flowpanel/adapter-drizzle

First public release. Drizzle ORM adapter for FlowPanel — Postgres, MySQL, and SQLite, with schema introspection, scoped queries, and soft-delete.

### @flowpanel/adapter-prisma

First public release. Prisma ORM adapter for FlowPanel, with schema introspection, scoped queries, and soft-delete.

### @flowpanel/charts

First public release. Recharts-backed chart widgets (area, bar, line, pie) for FlowPanel dashboards, loaded lazily.

### @flowpanel/cli

First public release. The FlowPanel CLI: `init`, `dev`, `migrate`, `doctor`, `eject`, and `new`.

### @flowpanel/client

First public release. Client-only React hooks (e.g. `useAdminMutation`) for wiring custom FlowPanel UIs to the server actions.

### @flowpanel/core

First public release. Core types and runtime for FlowPanel: `defineAdmin`, the `resource` / `dashboard` / widget builders, and the runtime for tenant scope, role gates, audit, and rate limiting.

### @flowpanel/eslint-plugin

First public release. ESLint rules that enforce FlowPanel config idioms — server-import boundaries, column-keyword typos, shorthand filters, unique resource names, and audited-action confirms.

### @flowpanel/kit

First public release. The umbrella package for FlowPanel — a config-first admin panel framework for Next.js 15. One `defineAdmin` config becomes a full `/admin` route; re-exports every subpackage (`@flowpanel/kit/next`, `/react`, `/drizzle`, `/prisma`, `/charts`, `/auth`).

### @flowpanel/next

First public release. The Next.js App Router integration: the admin page component, API route handlers, server-rendered list/detail/dashboard pages, drawers, server actions (row / bulk / dashboard / inline), and SSE realtime.

### @flowpanel/react

First public release. UI primitives for FlowPanel — shadcn-style components on Radix + Tailwind v4 with design tokens: the admin shell, data table, forms, feedback, and dashboard widgets.
