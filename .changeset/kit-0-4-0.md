"@flowpanel/kit": minor
---

- Added `@flowpanel/kit/styles/tailwind.css`, a Tailwind v4 bridge to FlowPanel's tokens.
- Added `llms/`, the whole documentation as plain text in one file per section, next to `llms.txt`.
- Removed the aliases deprecated in 0.3; see @flowpanel/core and the [upgrade guide](https://flowpanel.tech/docs/guides/upgrade).
- Fixed `llms.txt` opening with `> undefined`; it and the `llms/` files now include the config snippets and the compatibility table the docs show.
- Widened the optional queue peers to BullMQ 5 or 6, `@bull-board/*` 6 to 9, Express 4 or 5, and ioredis 5 or 6.
- Changed the Next.js peer range to `>=15.5.0 <17.0.0`, so Next.js 15.5 and newer 15.x releases work as well as 16.
- Breaking: removed `requireRole` from `@flowpanel/kit/server`; use `requireAccess(rule, context)`, which throws when the rule rejects the caller and denies when the rule is missing.
- Breaking: removed `authorizeOperation` (now `requireAccess`), `checkRequireRole`, `RequireRole`, `emitAudit` (still on `@flowpanel/kit/server`), `isBuiltinBulkDelete`, `assertCountWhereColumns` and `declaredWriteFields` from the `@flowpanel/kit` root.
