`flowpanel new <table> --dir <dir> [--hidden]` writes a resource as its own file — columns chosen by type, an `enumOf` stub per enum, a `reference` per foreign key, composite keys included — and adds it to `<dir>/index.ts`; `--dir` may be absolute, and `--json` reports an unlinked foreign key as `{ table, column }`. A root config that only re-exports another module is followed through the tsconfig paths. The Drizzle config template registers `schema` on `FlowpanelTypes`, and the better-auth session module registers `typeof auth.$Infer.Session`, so a new admin types its resources and session with no hand-written registry.

Behaviour changes. `flowpanel new` without `--dir` refuses a config whose `resources` is not an array literal and points at `--dir`, instead of adding a second `resources` key. The admin layout `init` writes into a host with its own root layout renders `ThemeScript` with the `x-nonce` header, so the theme applies before hydration there too — which means the theme script now marks the host's `<html>` before React hydrates it, so `init` also adds `suppressHydrationWarning` to that tag when it is missing (a no-op if it is already there, and a printed manual step if the layout cannot be parsed safely); a 0.3.0 host that already ran `init` should add the attribute by hand. `flowpanel eject resource` and `eject dashboard` now follow a root config that only re-exports another module the same way `new` does, and `eject resource` also follows a `resources` property imported from a one-file-per-resource directory to the file that actually defines the resource, instead of reporting it "not found". An enum stub `flowpanel new` writes labels its values with `humanize` (`past_due` becomes `"Past due"`, not `"past_due"`) and wraps a long stub onto its own lines; and the refusal for a config whose `resources` come from elsewhere no longer double-prefixes its message, and names the import it read the identifier from when it can. `flowpanel new` without `--dir` now accepts the SQL table name as well as the export name — `flowpanel new ai_usage` resolves to `export const aiUsage` and writes `schema.aiUsage` — matching what `--dir` already did.
