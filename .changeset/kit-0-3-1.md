"@flowpanel/kit": patch
---

Re-exports everything 0.3.1 adds to the public API of `@flowpanel/core`, `@flowpanel/next` and `@flowpanel/react`, but not the engine helpers behind `@flowpanel/core/internal`, and the root's `createPublisher` becomes a deprecated alias of `createRealtimeTransport`. `@flowpanel/kit/next` exports `adminWidgetContext` and `resolveWidget`, `@flowpanel/kit/publish` carries the worker publisher's `resource()`, `onError` and admin-options form, and `@flowpanel/kit/auth` types its presets with the registered session. `@flowpanel/kit/styles/tailwind.css` is a Tailwind v4 bridge to FlowPanel's tokens, generated from the stylesheet, so custom widgets can use `bg-fp-*`, `text-fp-*`, `rounded-fp*` and `shadow-fp-*` without copying the token list.

`llms.txt` documents every addition, and the package also ships `llms/`: the documentation one section per file, or one page per file for a section over 1,000 lines, with `llms/index.txt` naming each; the site serves the same files at `/llms/<file>`. The docs gain a founder-admin tutorial, the "Analytics from one query" guide, and guides for record pages and custom widgets.

`@flowpanel/kit/next` exports `flowpanelMetadata`, and the stylesheet and Tailwind bridge carry `--fp-data` (`bg-fp-data`).
